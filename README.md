# LargoVerse: původní webová adresa

Tento repozitář slouží pouze jako přesměrování původní GitHub Pages adresy na aktuální uzavřenou webovou betu na původním Cloudflare hostingu: https://largoverse-demo.pages.dev/

Původní osobní pozvánky ověřuje tento původní projekt. Přesměrování přenáší pouze jeden syntakticky platný parametr t o délce 32 hex znaků; jeho platnost následně ověřuje soukromá beta. Ostatní parametry a fragment se nepřenášejí. Odebrané ani vypršené pozvánky se neobnovují a nové přístupy zde nevznikají.

Tento web neobsahuje aplikaci, odemykací klíč, osobní pozvánku ani správu přístupů. Nemění uložená data v prohlížeči. Historie repozitáře zůstává zachovaná.
